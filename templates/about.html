About AI Under Attack

An AI Security Capture The Flag platform for learning Prompt Injection attacks through hands-on, interactive challenges.

Project Context

This platform was developed as part of COMP6441 (Security Engineering & Cyber Security) at UNSW Sydney. It is inspired by the GuidedCTF format used at UNSW, adapted for AI security threats that traditional CTF platforms do not cover.

As Large Language Models (LLMs) such as Claude, ChatGPT, and Gemini become embedded in production systems, Prompt Injection has emerged as one of the most critical and least understood attack surfaces. This platform gives students a safe environment to experience these attacks first-hand.

Challenge Categories

💉

Direct Prompt Injection

The attacker directly provides malicious input to an AI-powered application, overriding its system instructions to extract hidden information or change behaviour.

🎭

Role Manipulation

Also known as persona injection or jailbreaking. The attacker convinces the AI to adopt a different identity or operate under a fictional context that bypasses restrictions.

🔍

Information Disclosure

Sensitive data embedded in the AI's context (documents, credentials, instructions) is extracted through indirect questioning, completion attacks, or roleplay framing.

Security Engineering Principles

Each challenge is designed to demonstrate a failure of one or more security engineering principles:

  • Trust Boundaries: AI systems blur the boundary between instruction-giver and user — all input should be treated as untrusted.
  • Least Privilege: An AI assistant should never have access to more sensitive data than it needs to complete its task.
  • Defence in Depth: A single textual restriction in a system prompt is not a security control. Multiple independent layers are required.
  • Verification and Validation: AI output must be validated before it reaches the user or downstream systems.
  • Separation of Concerns: Credentials, secrets, and sensitive data must never be embedded in the AI's context window.

How to Use This Platform

  1. Read the Scenario tab to understand the target application and your goal.
  2. Read the Background tab to understand the attack category.
  3. Interact with the AI chat panel — try different prompt injection techniques.
  4. If you get stuck, reveal hints one at a time (avoid jumping to the last hint too quickly).
  5. Once you find the flag, submit it in the flag box. The format is always FLAG{...}.
  6. Read the Mitigation tab after completing the challenge to understand how it should have been fixed.

Responsible Use

This platform contains intentionally vulnerable AI systems for educational purposes only. The techniques demonstrated here should only be applied to systems you own or have explicit permission to test. Prompt injection attacks against production systems without authorisation may be illegal and unethical.
