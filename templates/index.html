What is Prompt Injection?

Prompt Injection is an attack technique where malicious input to an AI system overrides its intended instructions, causing it to behave in unintended ways — revealing secrets, ignoring safety guidelines, or performing unauthorised actions.

🛡️

Why Does It Matter?

LLMs are being embedded into customer service bots, internal tools, and critical systems. Without proper security design, any of these systems can be compromised by a malicious user who understands how to manipulate AI instructions.

🔬

How This Works

Each challenge provides a realistic AI-powered application. Interact with the embedded AI, use prompt injection techniques to extract the hidden flag, then read the write-up to understand the attack and its mitigations.
