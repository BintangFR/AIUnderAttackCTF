Suggested Learning Path (New to AI Security)
  1. Skim the OWASP LLM Top 10, it's the lay of the land
  2. Read Simon Willison's original prompt injection blog post, it's short, it's the OG, no excuse to skip it
  3. Go play Gandalf (Lakera). It's free, it's addictive, and it'll click faster than any article
  4. Work through Learn Prompting: Prompt Hacking for the structured version
  5. Come back here and actually do the challenges, save the hard ones for last
  6. Read the Greshake et al. (2023) paper if you want the "so this is a real research problem" version

Research Papers

7 resources
Ignore Previous Prompt: Attack Techniques for Language Models (2022)
Perez & Ribeiro's foundational paper formalising prompt injection as an attack class. Introduces the taxonomy used in most subsequent research. Essential reading.
IntermediatePaper
Not What You've Signed Up For: Indirect Prompt Injection (2023)
Greshake et al. - defines indirect prompt injection and demonstrates it against real LLM-integrated applications including Bing Chat, ChatGPT plugins, and code assistants.
IntermediatePaper
HackAPrompt: Exposing Systemic LLM Vulnerabilities (2023)
Schulhoff et al. - analysis of 600,000+ prompt injection attempts from the HackAPrompt competition. Categorises attack strategies and their success rates across models.
IntermediatePaper
Universal and Transferable Adversarial Attacks on Aligned LLMs (2023)
Zou et al. - demonstrates automated generation of adversarial suffixes that reliably jailbreak aligned LLMs including GPT-4. Shows limits of RLHF-based safety training.
AdvancedPaper
Jailbroken: How Does LLM Safety Training Fail? (2023)
Wei et al. - analyses why safety training fails against jailbreaks, identifying competing objectives and mismatched generalisation as root causes. Informs Challenge 2 on this platform.
AdvancedPaper
Injecting Relevance: Prompt Injection in RAG Systems (2024)
Explores prompt injection in Retrieval-Augmented Generation (RAG) systems where retrieved documents can contain malicious instructions - the real-world analogue of Challenge 5.
AdvancedPaper
Scaling Behaviour of Machine Learning Defences Against Prompt Injection (2024)
Analyses how well various defences (instruction hierarchy, spotlighting, sandwiching) scale as models grow - key reading for understanding why mitigations are hard.
AdvancedPaper

Security Tools & Scanners

5 resources
Garak - LLM Vulnerability Scanner
Open-source LLM security probe that automatically tests models for prompt injection, jailbreaks, hallucination, toxicity, and more. The Nmap of LLM security.
AdvancedTool
PyRIT - Microsoft Python Risk Identification Toolkit
Microsoft's open-source framework for red-teaming AI systems. Automates adversarial prompt generation and measures model resistance to attack categories.
AdvancedTool
Rebuff - Prompt Injection Detector
Open-source library that detects prompt injection attempts in real-time using a layered approach: heuristics, LLM-based detection, and vector embeddings.
IntermediateTool
Vigil - LLM Security Scanner
Python library for detecting prompt injection, jailbreaks, and PII leakage in LLM inputs and outputs. Useful for adding security layers to LLM applications.
IntermediateTool
Ollama Model Library
Browse locally-runnable LLMs. Different models have different safety training - experimenting with multiple models (Llama 3, Phi-3, Mistral) reveals how compliance varies.
BeginnerTool
